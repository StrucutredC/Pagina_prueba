# Ernesto — Personal Test

Página personal estática para practicar prompts, diseño de interfaz y despliegues con GitHub y Vercel.

## Tecnologías
- HTML, CSS y JavaScript (sin backend ni dependencias).
- Diseño responsive con estética cyberpunk minimalista y referencias renacentistas.
- Tres controles cambian el color del nombre ERNESTO.

## Ejecutar localmente
Abre `index.html` en un navegador. Para desarrollo, también puedes iniciar un servidor estático desde la carpeta del proyecto.

## Deploy
El repositorio está pensado para conectarse a Vercel como sitio estático. No requiere variables de entorno ni comandos de build.
